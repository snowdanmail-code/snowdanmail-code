# AI Remote Control GPT v2.1 — комплект для первого запуска на Android

**Реальное состояние:** Это исходники и сценарии сборки, не готовый APK. Настоящее Android APK можно получить через SDK/Gradle на Windows или приватную GitHub Actions. В этом окружении отсутствуют Android SDK и Gradle, поэтому сборка APK на телефоне не проверена. Реальные ставки в 1win в лабораторном APK жёстко отключены.

## Почему проверка без денежных ставок — обязательный первый этап

Визуальное распознавание отдельных карт/сумм, таймера и панелей протестировано на ограниченной выборке, но нет подтверждения работы полной цепочки **именно на телефоне**. Ошибка распознавания или повторный запрос могут вызвать финансовую потерю. Начинать денежный тест до полноценного захвата, связи, авторизации, диагностики и проверки экранов — неразумно.

## Windows → Android USB: самый простой безопасный путь

1. На Windows установи Python 3.11+, Java JDK 17, Android Studio с Android SDK 35 + Platform Tools и Gradle 8.9. Исходники можно открыть напрямую в Android Studio (`android/`). Без SDK сборка невозможна.
2. Открой PowerShell в папке проекта. Выполни `powershell -ExecutionPolicy Bypass -File .\windows\01_BUILD_APK.ps1`. При успешно пройденной сборке APK появится в `artifacts/` и будет выведен SHA-256. Если сборка завершилась ошибкой, APK не считается существующим.
3. Разреши **USB debugging** на своём Android; подключи телефон USB-кабелем. В PowerShell запусти `powershell -ExecutionPolicy Bypass -File .\windows\03_CONNECT_PHONE.ps1 -InstallApk`.
4. Запусти сервер `powershell -ExecutionPolicy Bypass -File .\windows\02_START_SERVER.ps1` (если есть установленный Python и сеть для скачивания библиотек). Он покажет случайный токен. **Не отправляй никому секреты или ключ OpenAI.**
5. В приложении укажи `http://127.0.0.1:8787`, введи локальный токен, разреши захват экрана через системный диалог. ADB reverse связывает телефон и локальный компьютер по USB; не открывай сервер во внешнюю сеть.
6. Запусти один диагностический кадр, поток наблюдения и самостоятельное касание тестовой кнопки **внутри AI Remote Control**. Проверяй статус, подключение и правильность изображения. При обнаружении реальных платёжных экранов немедленно останови запись.
7. Для отдельной проверки настоящего GPT задавай `OPENAI_API_KEY` только как переменную среды Windows (не в GitHub и не в приложении). Это может стоить денег за API; подписка ChatGPT не заменяет оплату API. В тестовом режиме агент описывает кадры и управляет только внутренней тестовой кнопкой.

## Отдельные проверки сервера

`python tools/offline_smoke.py` — реально запускает HTTP-сервер на случайном локальном порту, проверяет авторизацию, приём тестового JPEG и отсутствие произвольного endpoint для касаний. Никакого подключения к 1win или OpenAI не происходит.

`cd server && python -m unittest discover -s tests -q` — существующая серверная регрессия.

## Ограничения и нерешённые риски

- Нет собранного или испытанного APK в этом архиве. Сценарии Windows требуют предварительной установки SDK/Gradle.
- В 1win не проверены координаты, право на действие, ограничение банка и восстановление состояния после сети. Открытость приложения под наблюдением пользователя не гарантирует, что площадка разрешает автоматизацию.
- Не включай денежные ставки, пока не проверены аппаратные испытания и разрешённость способа интеграции. Тесты с реальными деньгами могут привести к потере баланса или блокировке аккаунта.
- Текущая версия не маскирует автоматизацию и не обходит защиту игрового клиента.

## Что было реально проверено в этой версии

- Offline HTTP roundtrip и отказ без авторизации.
- Сборочные входные требования через `android_preflight.py`.
- Регрессия Python-сервера. Полноценная Android APK-сборка — нет.
