# AI Remote Control GPT v2.3 — точная офлайн-вероятность появления аутов

## Что добавлено

**Read-only draw odds**: новый модуль `server/arc_poker_math/draw_odds.py`,
защищённый endpoint `POST /math/draw-odds` и ручной ввод карт в Android UI.
Для расчёта используется точная гипергеометрическая формула; интернет, GPT API
и оплата не нужны (локальный Python-сервер на Windows всё ещё необходим).
Ни касаний по игровому экрану, ни операций со ставками новый модуль не выполняет.

**Важно:** результат — вероятность появления хотя бы одной из *заранее указанных*
карт («аутов») на следующих общих картах. Это **не вероятность победы**:
карты могут не давать выигрышную комбинацию, и ауты вводит сам пользователь.
Рассчитываются только Hold'em флоп (3 карты стола) и тёрн (4 карты).

## API пример

```json
{
  "request": "math_draw_odds",
  "hero_cards": ["Ah", "Kh"],
  "board_cards": ["Qh", "Jh", "2c"],
  "outs_cards": ["2h", "3h", "4h", "5h", "6h", "7h", "8h", "9h", "Th"]
}
```

`POST /math/draw-odds` требует `X-Device-Token` (тот же секрет, что у сервера).
При 9 заданных аутах на флопе: вероятность следующей карты `9/47` (19.15%),
к риверу `1 - C(38,2)/C(47,2)` (34.97%). Если карты неверны, дублируются
или уже открыты, возвращается HTTP 422. Лишние поля, включая суммы ставок,
отклоняются (HTTP 400). Никакие данные не отправляются в OpenAI.

## Как проверить без оплаты

1. На Windows запустить локальный сервер по `README_RU_TEST.md` с токеном `ARC_DEVICE_TOKEN`.
2. На Android (после сборки debug APK) указать адрес сервера и тот же токен.
3. В разделе «Бесплатная математика» вручную ввести 2 карты руки,
   3–4 карты стола и список аутов. Нажать «БЕСПЛАТНО: точная вероятность аутов».
4. Ответ покажет вероятность следующей карты и к риверу, без GPT и ставок.
