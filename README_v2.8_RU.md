# AI Remote Control GPT — v2.8 (ИИ-игрок: протокол решений и памяти)

## Главная цель

Создать полноценного Android ИИ-игрока Texas Hold'em для испытаний в оригинальном установленном приложении 1win с **бесплатными условными фишками без денежной или призовой ценности**, под наблюдением оператора. ИИ должен принимать собственные стратегические решения, выбирать Fold/Check/Call/Bet/Raise, размер условной ставки и обоснованный блеф, следить за ходом игры и продолжать следующие раздачи. Название системы — **ИИ-игрок**. Оператор наблюдает, контролирует и имеет аварийный STOP.

**Важное различие между целью и текущим состоянием:** v2.8 не является уже действующим в 1win автономным игроком. В приложении 1win внешние жесты в данной лабораторной Android-конфигурации выключены. Модуль автономных решений работает в контролируемом исполнителе условных фишек. Доступ к ChatGPT Plus через официальный Sign in with ChatGPT не был завершён, реальные вызовы GPT не проверены. Здесь нет готового APK, поскольку Android SDK и Gradle отсутствуют.

## Реальные изменения этой версии

1. `server/arc_player/core.py`: неизменяемое состояние раздачи с ревизией, стратегический интерфейс GPT, проверка решений и отказ при неизвестном ходе или устаревшем кадре. Блокировка повторных действий и аварийная остановка.
2. `server/arc_player/gpt.py`: адаптер официального OpenAI Responses API со строгой схемой JSON; только GPT является стратегическим модулем. Локальная программа проверяет безопасные пределы, но не подменяет GPT скрытым набором правил.
3. `server/arc_player/lab.py`: контролируемый исполнитель `fold/check/call/bet/raise` для автономных испытаний без подключения к чужому приложению. Он возвращает факт принятия тестовой команды, не подтверждение её результата на экране.
4. `server/arc_player/memory.py`: память наблюдаемых действий соперников, сглаживание вероятностей и указание размера выборки; SHA-256 связанный журнал без возможности незаметного редактирования прошлых строк. Не записывать в журнал личные данные/учётные записи.
5. `android/.../PlayChipTurnGuard.kt`: Android-проверка допустимости действий, соответствия ревизии, лимитов, подтверждения двух последовательных кадров и стоп-сигнала. `MainActivity.kt`: локальная кнопка проверки команды Raise 80 условных фишек, STOP, обновлённые описание и версия.
6. Обновлены именование артефактов в CI, Windows-скриптах и Android preflight.

## Начало установки после сборки

Используйте Windows-скрипты `windows/01_BUILD_APK.ps1` и `windows/03_CONNECT_PHONE.ps1` при наличии Android SDK Platform 35, JDK 17 и Gradle 8.9, либо приватный GitHub Actions CI (`.github/workflows/ci.yml`), если репозиторий доступен. После получения APK провести операторские испытания чтения экрана с настоящим бесплатным столом 1win и журналированием ошибок. Внешнее исполнение игровых действий включать только при допустимости по применимым правилам 1win, без обхода защиты. Нельзя переходить на денежные ставки.

## Ближайшие незавершённые инженерные задачи

1. Реально собрать подписанный debug APK на Android SDK и установить на тестовый телефон.
2. Создать в Android полноценный сериализатор наблюдений под `GameSnapshot` и надёжную серверную привязку GPT решения к фактически распознанному состоянию (а не к значениям от самой GPT).
3. Завершить официальную авторизацию Sign in with ChatGPT при подтверждённой доступности для приложения; провести настоящий модельный вызов и измерить задержку.
4. Добавить подтверждение результата по новому кадру и учёт таймаутов/смены руки, законченную автономную сессию для разрешённого режима бесплатных фишек и журналирование с воспроизведением ошибок.

**Ни один из пунктов выше не считается завершённым в v2.8.**
