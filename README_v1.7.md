# AI Remote Control GPT — v1.7 Timer Label Reader

## Что реализовано

Новый модуль `server/arc_turn/timer_digits.py` **локально** распознаёт напечатанную метку `30 с` или `60 с` на уже известных вариантах круглого значка игрового таймера. Вход: либо полный JPEG-кадр разрешения, поддерживаемого старым детектором, либо нормализованный фрагмент 170×170 px. Используются бинарные шаблоны первой цифры, без OCR, LLM или сетевого вызова. При отсутствии значка, неподдерживаемом оформлении, слабом различии между шаблонами или перекрытии возвращается отказ.

`FastObserver` теперь выводит `timer_label` рядом с `stopwatch_cue`. Отдельный `LabelStabilizer` требует согласованных последовательных кадров, сбрасывает состояние после потери данных и игнорирует пришедшие не по порядку кадры. Модуль отдельный: его можно заменить/обновить без переписывания Android, математики и GPT-адаптера.

**Суть результата:** `displayed_label_seconds=30/60` — это надпись на значке, **не** подтверждённое число секунд до конца хода. `seconds_remaining=null`, `countdown_verified=false`, `turn_verified=false`, `money_actions_enabled=false` в каждом ответе. Таймер по кадрам не доказан как посекундно уменьшающийся, поэтому при вычислении дедлайна нельзя выводить оставшееся время из этой надписи.

## Проверки

- Python server: **291/291** unit/integration tests passed; запуск `cd server && python -m unittest discover -s tests -q`.
- Kotlin frame policy: **7 проверок** успешны; отдельная проверка LatencyWindow также успешна. Компиляции Android APK не было.
- Сохранённые полноэкранные скриншоты: 2 верно прочитанные метки 30 и 3 корректных отказа.
- Из двух наборов кадров одной исходной серии видеозаписей: 132 кадра с предварительно видимым значком, в 85 получена правильная метка, в 47 отказ. Ошибочных принятых меток не обнаружено; 781 кадр без значка был отклонён. **Это не независимый показатель точности**: шаблоны извлекались из того же оформления, кадры повторяются и новые условия не исследованы.
- Скорость CPU для самого считывателя: медиана ~0,03 мс для 170×170 фрагмента и ~1,09 мс для полного кадра. Время захвата Android, отправки, серверной очереди, GPT и касания не входит в измерение.
- Контрольные цифровые шаблоны и два небольших обезличенных 170×170 фрагмента включены, исходные видеозаписи и большие личные скриншоты в этот архив не добавлялись.

## Ограничения

Пока распознаются только `30` и `60` на одном типе интерфейса. Информация о фактическом количестве секунд до завершения хода неизвестна. Нет живого Android/GPT-испытания, APK, подключения к 1win или ставки на деньги. Изменения ограничены **наблюдением** — без управляющих касаний и без маскировки автоматизации.
