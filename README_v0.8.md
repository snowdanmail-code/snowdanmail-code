# AI Remote Control GPT — v0.8

## Что действительно изменилось

Версия развивает v0.7 без переписывания исходников: к серверу добавлен `arc_runtime/`, к Android-интерфейсу — кнопка просмотра активной контрольной точки.

- Сервер теперь **читает** из `arc_versions` активный лабораторный профиль, проверяя SHA-256 артефакта, цепочку журнала и состав релиза. Настройки реально применяются к наблюдениям.
- Два разных профиля: `0.8.0` — наблюдение при уверенности ≥0.82 и двух последовательных кадрах; `0.8.1` — более осторожный режим ≥0.94 и трёх кадрах.
- Переключение профиля через **локальную** контрольную точку вызывает сброс памяти наблюдателя; тестирование версий и откат не требуют переписывания серверного кода.
- Добавлен конечный автомат игровых экранов и контроль непротиворечивости полей, возраста и последовательности кадров.
- Правило «2 игрока за столом» учитывает **действительно сидящих**, а не только участвующих в текущей раздаче. По достижении условия выводится **информационный сигнал**, но никаких касаний не выполняется.
- Обработка реплея, пропавшего соединения, неизвестного состояния и неполных сведений — fail-closed.
- Реализован локальный визуальный подсказчик по обезличенным низкоразрешённым цветовым признакам. Он **не распознаёт карты или суммы** и **не является источником команд**. В архив не включены исходные видеозаписи и скриншоты пользователя.
- API: `GET /runtime/status`, `POST /runtime/observe`, `POST /runtime/frame-hint` — только чтение. Никаких маршрутов удалённого развёртывания, платежей или ставок.
- `POST /poker/screen` по желанию может прикладывать отчёт runtime при наличии `session_id`, `sequence`, `frame_age_ms`; старый контракт без этих полей поддерживается.

## Чего нет

- Нет собранного APK (в рабочем окружении нет Android SDK/Gradle), нет испытания на физическом телефоне.
- Нет подтверждённого live-запуска OpenAI API и гарантированной точности распознавания 1win.
- Нет проверенного автономного профессионального игрока; нет оценки стратегической доходности.
- Новые маршруты НЕ управляют оригинальным приложением 1win и НЕ размещают денежные ставки.
- Унаследованные экспериментальные средства внешнего управления v0.6 сохранены как исходники, но по умолчанию выключены. Не активируйте их на денежном балансе.
- Система контрольных точек **лабораторная**: не прошла проверку безопасного переключения на телефоне.

## Быстрая проверка на компьютере с Python 3.11+

```bash
cd server
python -m unittest discover -s tests
python -m arc_versions.cli --dir demo-registry --demo-offline status
python -m arc_versions.cli --dir demo-registry --demo-offline activate cp-demo-runtime-v0.8-1
python -m arc_versions.cli --dir demo-registry --demo-offline activate cp-demo-runtime-v0.8-0
```

Лабораторное тестирование API (режим ТОЛЬКО чтения):

```bash
# Сервер доступен только с устройства, на котором он работает. Не открывайте
# локальный development HTTP в публичный интернет.
export ARC_DEVICE_TOKEN='put-your-own-random-secret-here'
export ARC_VERSION_REGISTRY_DIR="$PWD/demo-registry"
export ARC_RUNTIME_LAB=1
python server.py
```

В другом терминале:

```bash
curl -H "X-Device-Token: put-your-own-random-secret-here" http://127.0.0.1:8787/runtime/status
```

Пример ответа: `checkpoint`, `policy_name`, `lab_only`, `money_actions_enabled:false`.

## Разработка Android

Откройте `android/` в Android Studio. Проект содержит Kotlin-исходники, но готового APK нет. Кнопка «Проверить текущую версию ИИ» обращается к `/runtime/status` с локально введённым токеном. `http://127.0.0.1:8787` допустим только при Debug и сервере на **этом же** Android; внешний сервер должен быть доступен через HTTPS.

## Опциональное распознавание на ПК

Зависимость: Pillow (`pip install -r requirements-vision.txt`). Видеозаписи не загружаются никуда этим модулем. `frame_hints.py` работает только с локальными JPEG и слабыми цвето-геометрическими признаками; в случае сомнения возвращает `unknown`.

Локальный первичный эксперимент на 19 вручную размеченных скриншотах из текущей беседы: 11 совпадений, 8 воздержаний, 0 уверенных ошибочных классификаций; выборка слишком мала, часть снимков использована также как эталон, поэтому это **не** оценка пригодности модели к эксплуатации. Исходные JPEG не включены в архив. Полные результаты находятся в `docs/frame_benchmark.json`.

## Безопасность данных

Ключ OPENAI_API_KEY хранится на сервере, не в APK. `X-Device-Token` — отдельный секрет. Запретите получение снимков экрана при открытии платёжных и личных разделов. Не используйте незащищённый публичный HTTP. Все новая функциональность работает без команд касаний; историю действия храним отдельно от переключаемых версий.

## Главный принцип дальнейшей разработки

1. Изменение стратегии/математики/зрения — только через версионированный модуль.
2. Автоматические и регрессионные тесты до создания контрольной точки.
3. В production переключение только после подтверждения безопасного состояния; лабораторные контрольные точки туда не подходят.
4. Ошибка или неподтверждённое состояние → остановка, а не угадывание.
5. Проверка реального APK, соединения, SDK и точности остаётся отдельным обязательным этапом.
