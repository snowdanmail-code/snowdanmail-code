## Что изменилось

**Модуль v2.4: read-only RTT diagnostic** — измерение времени ответа между Android и локальным Python-сервером. Он не отправляет JPEG, карты, данные аккаунта или ставки, не обращается к GPT и не инициирует касания.

- `GET /diagnostics/ping`: отдельный эндпоинт только для чтения. Требует `X-Device-Token` длиной от 12 символов, не принимает POST-команды. Отвечает коротким JSON с `action: null`, `money_actions_enabled: false`, `uses_openai_api: false` и `image_processed: false`. HTTP-ответ запрещён к кешированию.
- Android: кнопка «БЕСПЛАТНО: измерить задержку связи». Делает 7 последовательных запросов, первый — прогревочный; 6 остальных используются для медианы, p95, минимума и максимума. Ошибки считаются отдельно. Запросы выполняются в фоновом потоке, с таймаутом соединения/чтения по 3 секунды.
- `RttSummary.kt`: чистый Kotlin-модуль со статистикой RTT и состояниями `NO_CONNECTION`, `UNSTABLE_OR_INSUFFICIENT`, `LOW_RTT`, `MODERATE_RTT`, `HIGH_RTT`. Категории — диагностические ориентиры, не прогноз игрового исхода.
- Исправлены версии имени APK в двух Windows-скриптах, добавлена автоматическая проверка согласованности имён между Windows, Android и CI.
- В Android `versionName=2.4.0-lab`, `versionCode=24`; флаг `EXTERNAL_GAME_ACTIONS_ENABLED=false` сохранён.

## Как проверить после сборки на Windows

1. Установить JDK 17, Android SDK 35, Gradle 8.9, Platform Tools. Выполнить `windows/01_BUILD_APK.ps1`. APK появится только при **успешной** сборке; здесь он **не создан**.
2. Подключить Android по USB, разрешить USB debugging и выполнить `windows/03_CONNECT_PHONE.ps1 -InstallApk` (используется `adb reverse tcp:8787 tcp:8787`).
3. Запустить `windows/02_START_SERVER.ps1` и взять выданный секрет `ARC_DEVICE_TOKEN`.
4. В Android-приложении указать `http://127.0.0.1:8787` и токен. Нажать «БЕСПЛАТНО: измерить задержку связи».
5. Считать результат **только показателем RTT HTTP**: он не включает время захвата экрана, распознавания, GPT и реакции приложения. При 6 измерениях p95 соответствует самому медленному измерению (метод nearest-rank).
