# AI Remote Control GPT v2.6 — лаборатория стратегии и блефа

**База:** v2.5, SHA-256 `4a4ed1bab93856506754602becdc3e7a1f9d132c1229b0489ade5a2d44f27627`.

## Что сделано

Новый **изолированный** `lab_strategy/` использует **синтетические, не денежные** раздачи Texas Hold'em. Он генерирует учебные варианты fold/check/call/bet; для отсутствующей входящей ставки предлагает размеры 33/50/75% банка, оценивает упрощённый EV при предполагаемой вероятности фолда соперника, допускает как value-bet, так и обоснованные блеф-кандидаты. Блеф-кандидат требует поздней позиции, одного соперника, достаточного числа наблюдений, потенциального блокера, соответствующей структуры доски и положительного упрощённого EV после консервативной поправки на неопределённость.

`make_gpt_brief()` создаёт структурированный контекст учебной ситуации и вариантов для **будущего** GPT-анализа. `validate_lab_choice()` принимает результат такой гипотетической оценки и возвращает только объяснение и моделируемую линию: `execution_allowed: false`, `real_game_actions: []`. **GPT не вызывался**, связь с подпиской Plus пока не подтверждена. Старый исследовательский код управления Android и финансовые операции не затронуты; реальных ставок, связи с 1win или обхода ограничений нет.

Обсуждаемые ставки — условные фишки на искусственных раздачах, **не рекомендации для денежных игр**.
