# AI Remote Control GPT v2.2 — бесплатная локальная диагностика

## Что действительно работает в исходниках

Новый модуль **Offline Capture Diagnostics** принимает один JPEG с Android через локальный сервер на Windows/USB (либо HTTPS), проверяет его целостность и выдаёт ширину, высоту, размер и показатели яркости/контраста. Для него **не нужен OpenAI API**, и за вызовы не взимается плата OpenAI. Никаких карт, балансов или игровых команд модуль не распознаёт.

**Это исходники, не готовый APK.** Сборка Android по-прежнему требует Android SDK 35, Gradle 8.9 и JDK 17. На текущей машине Android SDK/Gradle нет; APK не был собран или установлен. Запуск на физическом телефоне не подтверждён.

## Как проверить на Windows

1. Установить зависимости из `server/requirements-vision.txt` в изолированное Python-окружение (Pillow обязателен).
2. Запустить локальный сервер по `README_RU_TEST.md` с секретом `ARC_DEVICE_TOKEN`; `OPENAI_API_KEY` для новой функции **не нужен**.
3. Собрать debug APK из папки `android/` с помощью Android Studio или `windows/01_BUILD_APK.ps1`, подключить Android по USB и выполнить ADB reverse как описано в `README_RU_TEST.md`.
4. Разрешить захват экрана и выбрать **«2. БЕСПЛАТНО: проверить качество кадра (без GPT)»**. На сервер уйдёт JPEG, ответ будет показан в приложении. Не захватывать экраны с паролями, банковскими реквизитами или личными данными.
5. Остановить захват и очистить кадр после теста.

## Контракт нового endpoint

`POST /offline/inspect` с заголовком `X-Device-Token` и JSON `{"request":"offline_inspect","image_base64":"..."}`. Ответ содержит `mode=offline_capture_diagnostics`, `uses_openai_api=false`, `action=null`, `money_actions_enabled=false` и диагностические поля. Не отправляет запросы в интернет, не использует ChatGPT Plus, не сохраняет кадры.

cd server

Kotlin/JVM проверки выполняются отдельно компилятором `kotlinc`; **не заменяют сборку Android APK**.

## Что с подпиской ChatGPT Plus

ChatGPT Plus не предоставляет обычный API-ключ или универсальную программную авторизацию стороннего Android-приложения. Здесь не реализована авторизация через ChatGPT, не используются cookie или токены веб-сессии. Для GPT-анализа через API требуется отдельная оплачиваемая интеграция; новый офлайн-модуль работает без неё.
