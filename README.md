# VPN Signal Lab v0.1
This is a diagnostic APK, not a VPN blocker or VPN hider. It uses no root and does not alter or patch other applications or the VPN client. No INTERNET permission.
Run with your third-party VPN enabled; copy report. Then exclude only VPN Signal Lab in split tunneling; refresh and compare. Do not exclude VK from VPN during this diagnostic experiment.
Multi-app choices are stored for reporting only and have no enforcement effect.
