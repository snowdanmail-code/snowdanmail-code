# AI Remote Control GPT — v2.10 (Operator STOP + Android tests)

**Это исходники, а не готовый APK.** GPT Plus не авторизован; живой Android-тест 1win не производился.

## Назначение

Android ИИ-игрок Texas Hold’em для тестирования на бесплатных условных фишках. ChatGPT — планируемый центральный стратег (решения, размеры ставок, оценка диапазонов, блеф); пользователь — оператор наблюдения с аварийным STOP. Внешние игровые нажатия отключены в лабораторной конфигурации до проверки применимых правил и работы интеграции. Режим распознавания предполагает проверку на настоящем экране 1win.

## Изменения относительно предыдущей версии

- Крупный постоянно видимый STOP вне области прокрутки; остановка вызывает прекращение сеанса, удаление кадра из буфера, блокирование новых игровых команд.
- После STOP новое наблюдение/сеанс требует отдельного разрешения оператора; разрешение не запускает действий автоматически.
- `OperatorControl.kt`: потокобезопасная защёлка остановки и чистые Kotlin-тесты.
- Android Gradle JVM unit tests проверяют STOP, повторные попытки Raise, старые кадры и запрет действий после остановки.
- `tools/build_android_debug.sh`: запускает `:app:testDebugUnitTest` до `:app:assembleDebug`, затем проверяет APK (`aapt`, `apksigner`, версию, SHA256). В облачной сборке результат публикуется как артефакт лишь при успешной проверке.

## Как собрать настоящий APK

**Windows**: нужны JDK 17, Android SDK Platform 35 + Build Tools 35.0.0 и Gradle 8.9. Выполнить `windows/01_BUILD_APK.ps1` из распакованной папки. Успешный результат — `artifacts/AI-Remote-Control-v2.10-PLAYER-LAB.apk`. Установку через USB выполняет `windows/03_CONNECT_PHONE.ps1`.

**Приватный GitHub**: загрузить содержимое исходников в закрытый репозиторий и вручную запустить `.github/workflows/ci.yml` через Actions / `workflow_dispatch`. После успешного завершения загрузить `ai-remote-control-v2.10-debug-apk` с APK, SHA256 и аттестацией. В подключённом GitHub репозитории сейчас отсутствуют; поэтому реальная облачная сборка не запускалась. Не публиковать личные скриншоты в открытом репозитории.

После сборки первое испытание — на телефоне с Android, под контролем оператора: разрешить тестовую сессию, выдать системное разрешение на захват экрана, настроить сервер, открыть бесплатный режим 1win, проверить распознавание, задержку и STOP.
