# v2.12 — Исправление пустых полей карт

- Точная диагностика: поля 2 карты / карты стола / ауты в v2.11 являлись ручным вводом. Кнопка диагностики кадра `/offline/inspect` не распознавала карты.
- Добавлена отдельная кнопка `РАСПОЗНАТЬ КАРТЫ С КАДРА (ЛОКАЛЬНО, БЕЗ GPT)`, вызывающая существующий локальный сервер `/vision/cards`.
- Добавлена `CardAutoFill`: заполнение руки и борда только при результате `quality=complete`, состоянии `live_table`/`showdown`, правильных картах и отсутствии повторов.
- При недостаточной уверенности поля не изменяются; автоматически выдумывать карты запрещено.
- При успешном распознавании старые ауты очищаются. Ауты по изображению автоматически НЕ вычисляются и не вставляются.
- versionCode 32, versionName 2.12.0-card-auto-fill; синхронизированы скрипты CI, Windows и проверки APK.
- Работа на Android не подтверждена: собран только исходный комплект, Android SDK отсутствует. Текущая версия v2.11 на телефоне не обновлена.
- Для работы кнопки нужен запущенный локальный сервер с `ARC_DEVICE_TOKEN`; `http://127.0.0.1:8787` относится к телефону, а не к облачному ChatGPT. Серверная модель распознавания локальна, не требует GPT; полнота шаблонов ограничена.
