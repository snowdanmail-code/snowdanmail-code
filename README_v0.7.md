# AI Remote Control GPT v0.7 — модульный каркас и контрольные точки

**База:** исходники v0.6 сохранены и расширены (не переписаны).  
**Новое:** `server/arc_versions/` — независимый реестр версий, контрольных точек и проверяемого отката.  
**Тесты:** подробный результат в `server/full-test-output.txt` и демонстрация в `server/lab-report.json`.  
**Статус:** локальный прототип, **не готовый APK**, не работающий автономный игрок 1win и не подключённый живой OpenAI API.

Папка `server/demo-registry/` содержит две лабораторные контрольные точки. Реальный код приложения в `android/` остаётся исходниками предыдущей версии; переход на следующую Android-сборку и сборка APK потребуют Android Studio.

Детали: `docs/README_VERSIONING.md` и `docs/CHANGELOG.md`.
