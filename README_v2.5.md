# AI Remote Control GPT v2.5 — лабораторный адаптер Sign in with ChatGPT

**Дата:** 17 октября 2026. **База:** проверенный архив v2.4, SHA-256 `91e17bde13f9d1e2fd6ed067b4269ee0bed45127ca0b70d16024d16be35fed9e`.

## Итог

Реализован **изолированный Python-модуль** `lab_auth/` для проверки архитектуры официального входа через ChatGPT Plus и последующего перехода на платный OpenAI API. Это **не готовый вход на Android**: реальный пользовательский OAuth-вход, выдача токенов и обращение к OpenAI **не выполнялись**. Приложение v2.4, игровой runtime и кнопки управления не подключены к этому модулю. Работа исключительно в безопасной лаборатории с синтетическими данными.

## Компоненты

- `oauth.py`: одноразовые `state`, `nonce`, PKCE S256, `dynamic_agent_client`, `agent_name_hint`, `ext_agent_host_id`, URL браузерной авторизации, строгая проверка loopback callback, получение выданного `client_id`, обмен кода и refresh с ротацией токенов. `PendingAuthorization` запрещает повторное использование callback в памяти; реальный loopback listener и UI — следующий этап.
- `identity.py`: проверка RSA SHA-256 подписи JWT по доверенным JWKS, OIDC `issuer`, `audience`, `exp`, `nonce`, subject; запрет чужого JWKS URI.
- `auth_flow.py`: завершение OAuth только после проверки ID-токена; отдельная проверка разрешения `chatgpt.tokens.use.direct`, контроль смены аккаунта.
- `storage.py`: прототип зашифрованного хранилища AES-256-GCM + Scrypt с атомарной заменой и правами `0600` на POSIX. Пароль не записывается на диск. **Не является завершённой интеграцией Android Keystore или Windows DPAPI.**
- `providers.py`: единый контракт `ModelProvider` для `ChatGPTPlanProvider` и `APIKeyProvider`, список моделей, строго фиксированный безобидный лабораторный запрос через Responses API (`store=false`, `stream=true`), подтверждение `response.completed`, обработка HTTP 401/403/429, ошибок SSE и лимитов подписки. Нет произвольного пользовательского запроса и нет автоматического перехода на платный ключ.
- CI: добавлены отдельные offline unit-тесты лабораторного адаптера (при будущем подключении GitHub).

## Не выполнено и ограничения

- **Нет** реального OAuth consent, ID-токена или проверки разрешений аккаунта; нет доказательства работоспособности Plus в этом приложении.
- **Нет** рабочего loopback listener/браузерной кнопки/Android Keystore/Windows DPAPI и безопасной интеграции с UI. Хранилище проверено на POSIX, не на Windows/Android.
- **Нет** реального списка моделей, GPT-ответа или расхода лимитов подписки.
- **Нет** собранного APK и испытаний на телефоне: Android SDK и Gradle недоступны в данной среде.
- **Нет** доступа к репозиторию для GitHub Actions.
- **Нет** реальных денежных ставок, подключения к 1win, автоматизации внешней игры, обхода антибот-систем.
- Официальная политика OpenAI запрещает использовать её сервисы для азартных игр на реальные деньги. Поэтому модуль строго изолирован от существующих игровых частей проекта.
